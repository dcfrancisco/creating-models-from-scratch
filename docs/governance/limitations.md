# Current Limitations

- Educational only.
- Early-stage repository; many work packages are still proposed.
- Tiny model scope and small fixture data.
- CPU-first design for constrained hardware.
- Character-level tokenizer only in the initial milestone.
- No alignment training.
- No production safety testing.
- No claim of factual reliability.
- PyTorch support is optional and compatibility-gated.
- Current implemented baseline is a count-based bigram model; the full tiny Transformer is still planned.
