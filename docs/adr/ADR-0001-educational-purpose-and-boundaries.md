# ADR-0001: Educational Purpose and Project Boundaries
- Status: Accepted
- Date: 2026-08-18

## Context
Repository starts empty; scope must stay learning-first.

## Decision drivers
Educational clarity, explicitness, evidence-based progression.

## Considered options
1. Tutorial wrapper around pretrained model
2. From-scratch staged implementation

## Decision
Adopt staged from-scratch learning architecture.

## Consequences
Slower early progress but deeper understanding.

## Risks
Scope creep toward production concerns.

## Validation evidence
Project charter and roadmap created.

## Revisit conditions
If learning outcomes are not being met.
