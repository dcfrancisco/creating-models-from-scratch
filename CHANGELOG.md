### Added
- Initial project skeleton for a learning-first tiny decoder-only language model.
- Documentation structure covering charter, roadmap, architecture, ADRs, work packages, guides, governance, and report templates.
- `tiny_llm` package with CLI, configuration loading, dataset utilities, character tokenizer, count-based bigram model, checkpointing, evaluation, generation, and experiment record support.
- Unit, numerical, and integration tests for the engineering baseline.
